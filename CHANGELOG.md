# Touchline changes

## Latest changes

- **Sound alerts** is beside **Pause clock** or **Resume clock**. It remains
  available at halftime.
- Use **What changed** in the update banner to read these notes on GitHub.
  The app and the current game stay open.

## Recent updates

- Use **Give positive feedback** under **About Touchline** to open a public
  GitHub feedback form. A GitHub account is required. No saved app data is included.
- Sound alerts last five seconds. Vibration is used where the browser supports it.
  The sound toggle shows whether sound is on or off.
- Blue field labels mark position changes. Green labels mark players who came
  on from the bench.
- Playing-time estimates show each half. Planning shows time played up to the
  selected block and marks bench waits longer than 15 minutes with a red dot.
